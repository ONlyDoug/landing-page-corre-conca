# Interface

## Componentes Ocultos (Pós-inscrições)
A seção de `Lotes` e o `Formulario` de inscrições foram ocultados ou comentados. Além disso, botões de ação ("Inscreva-se") foram removidos dos componentes `Hero`, `Modalidades` e `StickyMobileCTA`.

## Componente Kit
As informações de retirada (`data-testid="info-section"`) foram atualizadas com os textos provisórios: "Dia 4: Pela tarde" e "Dia 5: O dia inteiro", com local "A definir (Centro da cidade)". O componente também foi reposicionado no `app/page.tsx` para logo após o `Hero`, ganhando maior proeminência na página. O layout continua responsivo (`flex-col` para mobile, `flex-row` para desktop) e acessível (`role="region"`).
